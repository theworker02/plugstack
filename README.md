# plugstack

Plug encode/decode helpers for stack payloads in pipelines.

**Site:** https://theworker02.github.io/plugstack/

## Install / run

```bash
git clone https://github.com/theworker02/plugstack.git
cd plugstack
node src/cli.js
node --test
```
